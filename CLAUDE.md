# graphify
- **graphify** (`~/.claude/skills/graphify/SKILL.md`) - any input to knowledge graph. Trigger: `/graphify`
When the user types `/graphify`, use the installed graphify skill or instructions before doing anything else.

# humanizer
- **humanizer** (`~/.claude/skills/humanizer/SKILL.md`) – macht Texte menschlich, entfernt KI-Muster.
- Immer den humanizer-Skill verwenden, bevor du antwortest, wenn der Nutzer sagt: „schreib es menschlich“, „menschlich“, „menschlicher“, „klingt zu sehr nach KI“, „humanize“ oder `/humanizer` – auch mit Tippfehlern.
- Gilt für den zuletzt geschriebenen Text oder den Text, den der Nutzer nennt. Inhalt nicht ändern, nur den Stil.

# llm-council
- **llm-council** (`~/.claude/skills/llm-council/SKILL.md`) – 5 Berater + Chairman prüfen eine Entscheidung.
- Auch auf Deutsch auslösen: „Council“, „frag den Council“, „lass den Council drüber schauen“, „prüf das von allen Seiten“, „ich kann mich nicht entscheiden“ – bei echten Entscheidungen mit mehreren Optionen.
